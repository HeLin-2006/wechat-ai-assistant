# 🚗 长任务 Agent 设计：自驾游路书师

> 基于通用 Agent 骨架（Plan → Execute → Assemble），突出亮点：**多城市循环调用同一工具**。

## 1. 场景

用户一句话输入：
- 「规划一次成都到稻城亚丁的自驾游」
- 「做一份北京到青岛的自驾游路书」
- 「帮我规划三天杭州周边自驾路线」

Agent 自主完成：路线规划 → 逐城天气 → 日出日落 → 预算 → 自驾安全知识 → 海报 → 成文路书。

## 2. 子任务拆解与依赖

```
用户：「规划一次成都到稻城亚丁的自驾游」
  │
  ├─① 规划途经城市与每日里程(LLM) ──┬──▶ ② 逐城天气(TOOL_LOOP ×N) ──┐
  │                                ├──▶ ④ 预算(Skill计算器)        ├──▶ ⑥ 路书成文
  ├─③ 起点日出日落(工具链式) ────────┘                              │
  ├─⑤ 自驾安全RAG(独立) ─────────────────────────────────────────┘
  └─⑦ 路书封面(生图)
```

| 子任务 | 能力 | 说明 |
|---|---|---|
| ① 路线与每日里程 | LLM | 输出途经城市列表（结构化，供②循环） |
| ② **逐城天气** | **TOOL_LOOP** | **对路线每个城市循环调用 get_weather**（核心亮点） |
| ③ 日出日落 | TOOL_CHAIN | 坐标→日出 链式（决定每天出发时间） |
| ④ 预算 | SKILL+LLM | 油费/过路费/住宿/餐饮，calculator 逐项汇总 |
| ⑤ 安全知识 | RAG | 自驾知识库（高原/长途/车辆） |
| ⑦ 封面 | TOOL | generate_image |
| ⑥ 成文 | ASSEMBLER | 汇总为路书成品 |

## 3. 关键机制：TOOL_LOOP（多城市循环）

计划 JSON 增加 `loopOver` 字段：

```json
{
  "id": 2,
  "title": "查询每个途经城市天气",
  "capability": "TOOL_LOOP",
  "action": "get_weather",
  "loopOver": "route.cities",          // 取①输出的城市列表
  "dependsOn": [1]
}
```

Executor 解析 `loopOver`：把①的结果列表逐项作为 `get_weather(city=X)` 的参数循环执行，结果按城市聚合：

```
成都 → 晴 26℃ | 雅安 → 小雨 22℃ | 康定 → 多云 14℃ | 稻城亚丁 → 晴 8℃
```

> 这是"工具复用 × 数据驱动"的体现：**同一个 get_weather，Agent 决定循环调用 N 次**。

## 4. 模块划分

```
service/agent/                      复用出行规划的骨架
├── RoadTripAgentService            门面（或用通用 TravelAgentService）
├── AgentPlanner                    LLM 拆解目标 → 计划（含 loopOver）
├── AgentExecutor                   ★ 新增 TOOL_LOOP 分发
│     ├─ TOOL        → ToolRegistry.execute
│     ├─ TOOL_CHAIN  → ToolCallService（坐标→日出）
│     ├─ TOOL_LOOP   → 按 loopOver 列表循环调工具 ★新
│     ├─ SKILL       → SkillService
│     ├─ RAG         → RagService.retrieve
│     └─ LLM         → LlmClient.chat
├── AgentAssembler                  按路书章节模板成文
└── DriveKnowledgeBase              自驾 RAG 知识库 ★新
```

## 5. 自驾知识库（RAG 文档）

| 文档 | 关键词 | 内容 |
|---|---|---|
| 高原行车安全 | 高原/海拔/缺氧 | 川西高原注意：氧气、药物、勿剧烈运动… |
| 长途驾驶疲劳 | 疲劳/休息/服务区 | 每 2~4 小时休息、轮流驾驶… |
| 出行前车辆检查 | 车辆/检查/保养 | 胎压、刹车、机油、备胎… |
| 油费与过路费 | 油费/过路费/加油 | 高速收费规则、山区加油站间隔… |
| 山区道路驾驶 | 山路/弯道/落石 | 弯道减速、落石区域快速通过… |
| 天气与封路 | 封路/管制/冰雪 | 恶劣天气封路查询渠道… |

## 6. 成品：自驾路书（分章节）

```
🚗【成都 → 稻城亚丁】自驾路书
一、路线总览（途经城市 / 总里程 / 预计用时）
二、逐日行程（Day1 成都→康定，里程 330km，天气晴…）
三、逐城天气预报（成都/雅安/康定/稻城亚丁）
四、日出日落（建议出发时间）
五、预算明细（油费/过路费/住宿/餐饮 = 总计）
六、自驾安全与高原注意事项（RAG）
七、路书封面 🖼️
```

## 7. 容错与扩展

- 某城市天气查询失败 → 该城标注"暂缺"，不影响其他城市与成文
- loopOver 列表为空 → 跳过该步并在成品中提示
- 换路线：改一句话即可；换场景：换知识库+模板，骨架复用
